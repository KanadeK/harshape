# HarShape 中文说明

把 HAR 网络抓包转换为只保留性能结构的分享副本：保留耗时、状态、大小和相同端点的分组；主机名和路径逐段替换为本次文件内一致的 HMAC 代号，时间整体平移，丢弃请求/响应正文、头、Cookie、查询参数与未知扩展字段。

Python 3.11+，无运行时依赖、无网络请求。

```console
python -m pip install .
harshape original.har --output share.har
python examples/demo.py
```

输出文件必须尚不存在；源文件不修改。成功退出 0，格式、资源上限或操作错误退出 2。控制台只报告生成的统计信息。每次转换使用新的随机密钥，密钥和映射不保存，所以不同文件之间不能稳定关联代号。

HTTP(S) 的查询、片段、用户名/密码不保留；非 HTTP(S) 绝对 URL 整体作为不透明标识替换。时间从 2000-01-01 起计算，相对间隔保留至微秒；原始顺序不变。方法、协议、MIME 仅保留固定允许列表中的值，其他变成占位值。

**性能元数据仍可能揭示身份或应用特征，分享前必须自行检查。** 程序不能证明匿名性，不能重放请求，也不支持认证、正文或重定向排查。未验证所有浏览器和 HAR 查看器的导入兼容性。

仅支持 HAR 1.2、UTF-8（可含 BOM），必需字段不完整会失败。默认输入上限 32 MiB，最多 10,000 个请求、每 URL 8,192 字符，输出上限 64 MiB；完整 JSON 在内存中处理。POSIX 输出请求 0600 权限，Windows 继承 ACL。全部限制见 [英文说明](README.md)。

卸载：`python -m pip uninstall harshape`。工具不创建缓存或配置，请按需清理原抓包、分享副本和虚拟环境。
